# Future USA Tileset

Source: `resources/tilesets/futureusa/*` from
<https://github.com/SimHacker/MicropolisCore/tree/main/resources/tilesets/futureusa>.

The checked-in PNG files used by the web runtime adapters are:

- `tiles.png` for map tiles.

Alpha-baked object variants (`*-alpha.png`) are generated by
`packages/sim-assets/scripts/export-micropoliscore-object-alpha-images.mjs`
and preferred by the runtime object-sheet adapter.
